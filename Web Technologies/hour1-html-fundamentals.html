01 Foundations

What is HTML?

HyperText Markup Language is the standard markup language used to define the structure and meaning of content on a web page. It is not a programming language — it has no loops, conditions, or functions. It only describes what content is, not what it does.

The house analogy

Think of building a website like building a house. HTML is the walls and rooms, CSS is the paint and furniture, and JavaScript is the wiring and automation. Each layer has one job.

HTML · CSS · JAVASCRIPT — THE THREE LAYERS OF A WEBPAGE

What the browser sees

When HTML says <h1>, it's telling the browser "this is a heading" — not how big, what color, or what font. Presentation is CSS's job; HTML only declares meaning.

example.html HTML
i

HTML has no logic. There's no "if the user is logged in, show this" in HTML — that reasoning belongs to JavaScript. Keep this distinction sharp: it's the most common early confusion for new developers.

02 Foundations

What is HyperText?

HyperText is text that can contain links to other resources or pages. It's "hyper" because it breaks the linear flow of a document — a reader can jump anywhere with a click.

link.htmlHTML

Clicking the visible text Visit Website navigates the user to https://example.com — the link's destination is stored as an attribute, not shown directly.

03 Foundations

What is a Markup Language?

A markup language uses tags to describe content — wrapping raw text with labels that tell the browser what role that text plays.

TAG ANATOMY — HOW A MARKUP TAG WRAPS CONTENT

Opening tag + content + closing tag together form a single HTML element — the next topic.

04 Anatomy

HTML Element

An element is the complete unit: opening tag + content + closing tag. "Tag" and "element" are related but not identical — the tags are the markers, the element is the whole package.

Headings

HTML gives you six heading levels — h1 through h6. Choose them by document hierarchy, never by how big or small you want text to look — that's CSS's job.
