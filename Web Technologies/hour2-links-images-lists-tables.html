03 Media

Images

The <img> tag is a void element — no closing tag, no wrapped content. Everything about it is configured through attributes.

image.htmlHTML
AttributePurpose
srcWhere the image file lives.
altAlternative text — read by screen readers, shown if the image fails to load, and important for accessibility.

Real-life example: an e-commerce product

product.htmlHTML
i

Write alt text the way you'd describe the image over the phone — specific and useful, like "Black laptop with 15 inch display," not "image1" or "laptop.jpg."
