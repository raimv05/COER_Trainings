What is an HTML Form?

03 Input types

Text, Password, Email & More

Choosing the right type gives you free browser behavior — validation, masking, mobile keyboards — without writing any logic yourself.

type="text"
Plain single-line text.
type="password"
Masks entered characters.
type="email"
Browser-level email validation.
type="number"
Numeric input, with min/max.
type="date"
Native date picker.
type="tel"
Phone number, numeric keypad on mobile.
type="url"
Validates as a web address.

08 Submitting data

Button

TypeBehavior
type="button"Does nothing on its own — used to trigger custom JavaScript.
type="submit"Submits the form using its action and method.
type="reset"Clears all fields back to their default values.
buttons.htmlHTML
i

Explicitly specifying the button type inside a form is a good professional habit — a bare <button> defaults to submit, which surprises developers who only wanted a click handler.
