Recursion

A method that calls itself to solve a smaller version of the same problem

🧩 The Simplest Way I Can Put It

Recursion means a method calls itself
↓
to solve a smaller version of the same problem

📁 A Real-Life Example — Opening Folders

Imagine you need to search every file inside a folder, including whatever is inside every subfolder:

Folder A
├── File
├── Folder B
│   ├── File
│   └── Folder C
│       └── File

To search every folder, the same operation — "look at what's inside, and if it's a folder, search it too" — can be repeated for each subfolder, no matter how deeply nested it is. That repeating-the-same-operation-on-a-smaller-piece idea is exactly what recursion is.

✅
Every recursive method needs two things: a base case — the smallest version of the problem, where the method stops calling itself and just returns an answer directly — and a recursive case, where it calls itself again on a smaller piece of the problem, moving one step closer to that base case each time.

Basic Recursion

Counting down to zero, one recursive call at a time

⏱️ A Countdown Timer

RecursionDemo.java
public class RecursionDemo {

    static void countDown(int number) {

        if (number == 0) {

            return;

        }

        System.out.println(number);

        countDown(number - 1);

    }

    public static void main(String[] args) {

        countDown(5);

    }
}
Output5 4 3 2 1

🔍 Identifying the Base Case and Recursive Case

Step 1 — The base case

if (number == 0) { return; } — this is where the recursion stops. Without this, the method would call itself forever.

Step 2 — The recursive case

countDown(number - 1); — the method calls itself again, but with a smaller value, moving one step closer to the base case every time.

Step 3 — Trace it call by call

countDown(5) prints 5, then calls countDown(4), which prints 4, then calls countDown(3) — and so on, until countDown(0) hits the base case and simply returns, ending the chain.

countDown(5) → print 5
↓ calls countDown(4)
countDown(4) → print 4
↓ calls countDown(3)
countDown(3) → print 3
↓ ... continues down to 1
countDown(0) → base case → return, no more calls
🚫
The bug every beginner eventually writes: forgetting the base case, or writing one that's never actually reached. Either mistake causes infinite recursion, which eventually crashes the program with a StackOverflowError — the recursive equivalent of an infinite loop.

Factorial

The classic recursion example — and for good reason

✖️ The Math First

5! = 5 × 4 × 3 × 2 × 1
↓ which can be rewritten recursively as
n! = n × (n − 1)!

Notice that n! is defined in terms of itself — that's precisely the shape every recursive method follows.

💻 The Code

Factorial.java
public class Factorial {

    static int factorial(int n) {

        if (n == 0 || n == 1) {

            return 1;

        }

        return n * factorial(n - 1);

    }

    public static void main(String[] args) {

        System.out.println(factorial(5));

    }
}
Output120
n == 0 || n == 1
Base case — both 0! and 1! equal 1 by definition, so we stop recursing here.
n * factorial(n - 1)
Recursive case — multiply n by the factorial of everything smaller than it.
💡
Why the base case checks both 0 and 1: mathematically, 0! = 1 is a defined special case, and 1! also equals 1. Covering both means factorial(0) and factorial(1) both return immediately without needing an extra recursive call.

Explain the Call Stack

Where recursion actually happens in memory — an excellent bridge into stack memory

📉 Phase 1 — Going Down (Calls Pile Up)

Watch what happens when factorial(5) starts. Each call pauses and waits, stacking on top of the one before it, because it needs the result of the smaller call before it can finish its own multiplication:

↓ Calls stack up

factorial(5)
5 × factorial(4)
4 × factorial(3)
3 × factorial(2)
2 × factorial(1)
factorial(1) → base case → returns 1

↑ Results unwind back up

1
2 × 1 = 2
3 × 2 = 6
4 × 6 = 24
5 × 24 = 120

Nothing actually multiplies until factorial(1) hits the base case and returns 1. Only then does every waiting call finish its own multiplication, one level at a time, unwinding back up to the very first call.

🗂️ Visualizing It as a Literal Stack

↑ top of stack = most recently called, resolves first
factorial(1) → returns 1
factorial(2) waiting on factorial(1)
factorial(3) waiting on factorial(2)
factorial(4) waiting on factorial(3)
factorial(5) waiting on factorial(4)

Each recursive call gets pushed onto the call stack as its own frame, waiting for the call above it to finish. This is genuinely the same call stack every Java method uses — recursion just pushes many frames of the same method onto it in a row.

✅
Why this matters beyond factorial: this is exactly why a missing or unreachable base case causes a StackOverflowError — the stack keeps growing with new frames that never get to return, until it runs out of space. Understanding this call-stack picture is what makes recursion click for most students.

Final Integrated Mini-Project

Student Management System — bringing all eight hours together

🎯 Requirements

1 Add student
2 Display student
3 Calculate average marks
4 Determine grade
5 Exit

Plan on spending approximately 30–40 minutes building and walking through this together — it's the payoff for everything covered across the last eight hours.

🔄 How the Menu Loop Works

do { show menu, read choice }
1 → inputStudent()
2 → displayStudent()
3 → print "Thank you!"
↻ while (choice != 3)

This is Module 29's do-while and Module 30's switch, working together — the menu always shows at least once, and keeps re-showing until the student explicitly chooses to exit.

💻 Complete Beginner-Friendly Implementation

StudentManagementSystem.java
import java.util.Scanner;

public class StudentManagementSystem {

    static String studentName;
    static int[] marks = new int[3];

    static void inputStudent(Scanner scanner) {

        System.out.print("Enter student name: ");
        studentName = scanner.nextLine();

        for (int i = 0; i < marks.length; i++) {

            System.out.print("Enter marks for subject " + (i + 1) + ": ");

            marks[i] = scanner.nextInt();

        }

        scanner.nextLine();
    }

    static double calculateAverage() {

        int total = 0;

        for (int mark : marks) {

            total += mark;

        }

        return (double) total / marks.length;
    }

    static String calculateGrade(double average) {

        if (average >= 90) {

            return "A+";

        } else if (average >= 80) {

            return "A";

        } else if (average >= 70) {

            return "B";

        } else if (average >= 60) {

            return "C";

        } else if (average >= 40) {

            return "D";

        } else {

            return "F";

        }
    }

    static void displayStudent() {

        double average = calculateAverage();

        System.out.println("\n----- Student Details -----");

        System.out.println("Name: " + studentName);

        System.out.println("Marks:");

        for (int mark : marks) {

            System.out.println(mark);

        }

        System.out.println("Average: " + average);

        System.out.println("Grade: " + calculateGrade(average));

    }

    public static void main(String[] args) {

        Scanner scanner = new Scanner(System.in);

        int choice;

        do {

            System.out.println("\n===== Student Management System =====");

            System.out.println("1. Add Student");

            System.out.println("2. Display Student");

            System.out.println("3. Exit");

            System.out.print("Enter your choice: ");

            choice = scanner.nextInt();

            scanner.nextLine();

            switch (choice) {

                case 1:

                    inputStudent(scanner);

                    break;

                case 2:

                    displayStudent();

                    break;

                case 3:

                    System.out.println("Thank you!");

                    break;

                default:

                    System.out.println("Invalid choice.");

            }

        } while (choice != 3);

        scanner.close();

    }
}

🧭 Walking Through It Method by Method

Step 1 — inputStudent(scanner)

Reads the student's name, then loops through the marks array (from Module 44–46) collecting one score per subject.

Step 2 — calculateAverage()

Sums every value in marks using an enhanced for loop, then divides by marks.length — casting to double first so the division doesn't truncate, exactly like Module 21's type conversion lesson.

Step 3 — calculateGrade(average)

An else-if ladder, top to bottom, straight from Module 24 — the first threshold that matches decides the grade.

Step 4 — displayStudent()

Calls both calculateAverage() and calculateGrade(), showing how one method's return value can feed directly into another.

Step 5 — main() menu loop

A do-while loop wrapping a switch — the menu always displays at least once, and keeps looping until the student picks option 3 to exit.
