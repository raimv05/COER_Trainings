3.1

What is Selenium?

Selenium is an open-source browser automation ecosystem — not a single tool, but a family of them. The component beginners should learn first is Selenium WebDriver.

Selenium WebDriver

WebDriver drives browsers natively and exposes an API for interacting with web applications — clicking elements, typing into fields, reading page state — the same actions a human tester performs by hand.

3.2

Selenium Architecture

A single WebDriver command travels through several layers before a browser actually does anything:

Java Test Code
Selenium WebDriver
Browser Driver (WebDriver implementation)
Chrome / Firefox / Edge
Web Application

Beyond one-way commands: WebDriver BiDi

Modern Selenium also includes WebDriver BiDi capabilities, extending automation toward bidirectional communication — letting scripts listen for things like network events and console errors rather than only sending commands downward.

Create First Selenium Project

Three steps stand between an empty machine and a project ready to run WebDriver code.

STEP 1Install Java

Use Java 17 or newer.

$ java -version

STEP 2Install IntelliJ IDEA

Create a new project through this path:

New Project
Java
Maven

STEP 3Create pom.xml

This file tells Maven which libraries the project depends on.

pom.xml 
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="
         http://maven.apache.org/POM/4.0.0
         https://maven.apache.org/xsd/maven-4.0.0.xsd">

    <modelVersion>4.0.0</modelVersion>

    <groupId>automation.training</groupId>
    <artifactId>selenium-training</artifactId>
    <version>1.0-SNAPSHOT</version>

    <properties>
        <maven.compiler.source>17</maven.compiler.source>
        <maven.compiler.target>17</maven.compiler.target>
    </properties>

    <dependencies>

        <dependency>
            <groupId>org.seleniumhq.selenium</groupId>
            <artifactId>selenium-java</artifactId>
            <version>4.48.0</version>
        </dependency>

        <dependency>
            <groupId>org.testng</groupId>
            <artifactId>testng</artifactId>
            <version>7.12.0</version>
            <scope>test</scope>
        </dependency>

    </dependencies>

</project>

Trainer note

4.48.0 and 7.12.0 were the current stable Maven Central releases for selenium-java and testng as of late August 2026. Both libraries ship frequently — have students check Maven Central for the current stable version at delivery time rather than copying these numbers as permanent truth.

3.4

First Selenium Program

Create the test file inside the standard Maven source layout:

src
└── test
└── java
└── FirstSeleniumTest.java
FirstSeleniumTest.java 
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;

public class FirstSeleniumTest {

    public static void main(String[] args) {

        WebDriver driver = new ChromeDriver();

        driver.get("https://www.google.com");

        System.out.println("Title: " + driver.getTitle());

        driver.quit();
    }
}

This is the standard pattern, not a shortcut

Selenium's own first-script documentation follows this same basic shape: create a browser session, interact with the browser, then close the session. Every WebDriver script — however complex — is built on that same three-part skeleton.

Implementation Steps

The same program, broken into the seven decisions a beginner actually makes.

1

Create Maven project

Set up the project skeleton IntelliJ generates from New Project → Java → Maven.

2

Add Selenium dependency

Declare selenium-java inside pom.xml so Maven downloads the WebDriver libraries.

3

Create Java class

Add FirstSeleniumTest.java under src/test/java.

4

Create WebDriver

Instantiate a browser session.

WebDriver driver = new ChromeDriver();
5

Open website

Navigate the browser to a URL.

driver.get("https://www.google.com");
6

Print title

Read back page state to confirm the browser actually loaded the page.

System.out.println(driver.getTitle());
7

Close

Always end a session — an open browser process left behind is a common beginner mistake.

driver.quit();
3.5

Browser Commands

A small set of WebDriver commands covers most day-to-day navigation and inspection needs.

BrowserCommands.java 
driver.get("https://example.com");

driver.getTitle();

driver.getCurrentUrl();

driver.navigate().back();

driver.navigate().forward();

driver.navigate().refresh();

driver.quit();
CommandWhat it does
driver.get(url)Loads the given URL in the current browser window.
driver.getTitle()Returns the current page's title — useful for quick assertions.
driver.getCurrentUrl()Returns the URL currently loaded in the browser.
driver.navigate().back()Goes back one step in browser history, like the back button.
driver.navigate().forward()Goes forward one step in browser history.
driver.navigate().refresh()Reloads the current page.
driver.quit()Closes every window the driver opened and ends the session.
