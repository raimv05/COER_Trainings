4.1

What is ROI?

ROI stands for Return on Investment. In automation, the question it answers is simple to state and easy to skip:

The question that matters

Does the investment in creating and maintaining automation save enough time or cost to justify itself? If the answer is no, automating a test isn't a technical win — it's wasted engineering time.

4.2

Simple Example

A manual test takes 10 minutes and needs to run 100 times. Here's how manual effort compares to automation effort over that same 100 runs.

Manual
Execution time10 min
Number of executions100
Manual effort10 × 100 = 1,000 min
Automation
Development (one-time)300 min
Execution (100 runs)1 × 100 = 100 min
Total automation effort300 + 100 = 400 min
Saving over 100 executions 1,000 − 400 = 600 minutes
4.3

Simple ROI Formula

For training purposes, ROI can be expressed with a straightforward formula:

Benefits − Automation Cost Automation Cost
× 100 = ROI %

Worked example

Benefit₹100,000
Cost₹40,000
150% (100,000 − 40,000) / 40,000 × 100
