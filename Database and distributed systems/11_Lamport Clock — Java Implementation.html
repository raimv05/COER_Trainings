LAMPORT CLOCK JAVA IMPLEMENTATION

The Process class

Process.java 
class Process {

    private String name;
    private int clock = 0;

    public Process(String name) {
        this.name = name;
    }

    public int internalEvent() {

        clock++;

        System.out.println(
                name + " internal event -> Clock = " + clock);

        return clock;
    }

    public int sendMessage() {

        clock++;

        System.out.println(
                name + " sends message -> Clock = " + clock);

        return clock;
    }

    public void receiveMessage(int receivedClock) {

        clock = Math.max(clock, receivedClock) + 1;

        System.out.println(
                name + " receives message -> Clock = "
                        + clock);
    }
}
LAMPORT CLOCK JAVA IMPLEMENTATION

The LamportDemo main class

LamportDemo.java 
public class LamportDemo {

    public static void main(String[] args) {

        Process p1 = new Process("Process-1");
        Process p2 = new Process("Process-2");

        p1.internalEvent();

        int messageTimestamp =
                p1.sendMessage();

        p2.receiveMessage(messageTimestamp);

        p2.internalEvent();

        int secondMessage =
                p2.sendMessage();

        p1.receiveMessage(secondMessage);
    }
}

Notice E4 is not in the chain — it happened on P2 but has no causal relationship to E1 or E2. Lamport timestamps preserve exactly this causal relationship: they respect every genuine "happened-before" link without inventing false ones between unrelated events.

11.2 INDUSTRIAL CONNECTION

📬Message ordering

Modern distributed messaging systems often deliberately define ordering scopes rather than assuming a universal global order. Kafka, for example, provides total ordering within a partition while allowing partitions to execute in parallel — the same trade-off logic we've been building toward all hour.

Hour 11 — Key takeaways

☕ A complete, reusable class

Process encapsulates internalEvent(), sendMessage(), and receiveMessage() around a single clock field.

🧪 The demo is fully deterministic

Given the same sequence of calls, LamportDemo always produces the same six clock values, 1 through 6.

🧭 Causality, not coincidence

E1 → E2 → E3 → E5 is preserved exactly, while unrelated E4 correctly stays outside the chain.

🏭 This is production-grade thinking

Kafka and other systems scope ordering deliberately — total order within a partition, not across the whole system.
