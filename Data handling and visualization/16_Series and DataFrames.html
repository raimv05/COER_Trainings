Series and DataFrames

4.1

What is a Series?

A one-dimensional array with labels attached to every value

📘 Definition

A Pandas Series is a one-dimensional labeled array. It stores values with an associated index — so every value has both a position and a name you can use to reach it.

series_basics.py
import pandas as pd

salaries = pd.Series(
    [45000, 50000, 55000],
    index=["Rahul", "Priya", "Amit"],
    name="salary"
)

print(salaries)
print("Rahul's salary:", salaries["Rahul"])
print("Average salary:", salaries.mean())
OutputRahul 45000 Priya 50000 Amit 55000 Name: salary, dtype: int64 Rahul's salary: 45000 Average salary: 50000.0
indexsalary
Rahul45000
Priya50000
Amit55000

The amber column is the index — a label for every row. salaries["Rahul"] looks up a value by that label, the highlighted row above, not by counting positions.

💡
Why labels matter: a plain Python list only lets you access list[0], list[1], and so on. A Series lets you access salaries["Rahul"] directly — labels let you reach a value by name, not just by remembering its numerical position.
4.2

What is a DataFrame?

Several Series, sharing one index, arranged side by side

📘 Definition

A DataFrame is a two-dimensional labeled structure containing rows and columns. Unlike a NumPy array, different columns can hold different data types — text in one, whole numbers in another, decimals in a third.

dataframe_basics.py
import pandas as pd

employees = pd.DataFrame({
    "employee_id": [101, 102, 103],
    "name": ["Rahul", "Priya", "Amit"],
    "department": ["IT", "HR", "IT"],
    "salary": [45000, 50000, 55000]
})

print(employees)
Output employee_id name department salary 0 101 Rahul IT 45000 1 102 Priya HR 50000 2 103 Amit IT 55000
employee_idnamedepartmentsalary

1102PriyaHR50000
2103AmitIT55000

Each column here — employee_id (integers), name/department (text), salary (integers) — is really its own Series. The DataFrame is what holds them all together, sharing the same row index on the left.

4.3

Add and Update Columns

Deriving new columns from existing ones — with ordinary arithmetic

➕ Calculating Annual Salary and Bonus

Suppose the company wants to calculate an annual salary and give each employee a 5% bonus — both derived directly from the existing salary column.

add_columns.py
import pandas as pd

employees = pd.DataFrame({
    "name": ["Rahul", "Priya", "Amit"],
    "salary": [45000, 50000, 55000]
})

employees["annual_salary"] = employees["salary"] * 12
employees["bonus"] = employees["salary"] * 0.05

print(employees)
Output name salary annual_salary bonus 0 Rahul 45000 540000 2250.0 1 Priya 50000 600000 2500.0 2 Amit 55000 660000 2750.0
namesalaryannual_salarybonus
0Rahul450005400002250.0
1Priya500006000002500.0
2Amit550006600002750.0

The two new teal columns didn't exist before this script ran — assigning to employees["new_name"] creates the column automatically if it isn't there yet.

📝
The pattern to remember: df["new_column"] = df["existing_column"] * some_value — an entire new column, calculated in one line, with no loop. This is the same element-wise thinking from NumPy arithmetic, applied to DataFrame columns.
4.4

Update Values and Remove Columns

Changing one specific cell by condition, and dropping a column entirely

✏️ Conditional Update with .loc[]

update_remove.py
# Update a specific employee's salary using a condition
employees.loc[employees["name"] == "Rahul", "salary"] = 47000

# Remove the bonus column from the DataFrame
employees = employees.drop(columns=["bonus"])

print(employees)
Output name salary annual_salary 0 Rahul 47000 540000 1 Priya 50000 600000 2 Amit 55000 660000
namesalaryannual_salarybonus
0Rahul470005400002250.0
1Priya500006000002500.0
2Amit550006600002750.0

The violet cell shows the targeted update — only Rahul's row changed. The coral column shows bonus being dropped entirely from the DataFrame.

💡
Read .loc[row_condition, "column"] as a sentence: "find the rows where name == 'Rahul', and in the salary column for those rows, set this value." It updates in place, by condition, instead of needing to know a row's numerical position.
4.5

Rename Columns

Giving columns clearer, more descriptive names

🏷️ Using .rename()

rename_columns.py
employees = employees.rename(columns={
    "name": "employee_name",
    "salary": "monthly_salary"
})

print(employees)
Output employee_name monthly_salary annual_salary 0 Rahul 47000 540000 1 Priya 50000 600000 2 Amit 55000 660000
"name" → "employee_name"
↓ .rename(columns={...})
"salary" → "monthly_salary"

📝
The dictionary maps old → new: each key in columns={...} is the current column name, and its value is what you want it renamed to. Only the columns you list are renamed — everything else, like annual_salary here, is left untouched.
