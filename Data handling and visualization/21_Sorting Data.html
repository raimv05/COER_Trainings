9.1

What is Sorting?

Arranging records in a meaningful order

📘 Definition

Sorting arranges records in a particular order — highest salary first, lowest price first, or newest order first.

Best-selling productshigh → low
Employees ranked by performancehigh → low
Most expensive productshigh → low
Cheapest deals firstlow → high
Newest order firstnew → old
Unordered rows
↓
sort_values(by=..., ascending=...)
↓
Same rows, new order

Sorting never changes what the data says — only the order it is shown in.

9.3

Smallest value first

⬆️ ascending=True

    by="salary",
    ascending=True

9.5

Sort by Multiple Columns

Department first, then salary within each department

🗂️ Two-level sorting

HR wants employees sorted by department, and within each department by salary, highest first. Give by a list of columns and ascending a matching list of directions.

sort_multiple.py
sorted_employees = employees.sort_values(
    by=["department", "salary"],
    ascending=[True, False]
)

print(sorted_employees)
Output name department salary experience 3 Sneha Finance 50000 5 1 Priya HR 60000 4 4 Vikas HR 40000 1 2 Amit IT 55000 3 0 Rahul IT 45000 2
namedepartmentsalaryexperience
3SnehaFinance500005
1PriyaHR600004

2AmitIT550003

Level 1 — department
ascending=True → Finance, HR, IT (A → Z)
Level 2 — salary
ascending=False → inside HR: Priya 60000 before Vikas 40000; inside IT: Amit 55000 before Rahul 45000
⚠️
Order of the lists matters: the first item in by pairs with the first item in ascending. Pandas sorts by the first column, and only uses the second to break ties.
9.6

Generate Rankings

Turn values into rank positions with rank()

🏅 rank(method="dense", ascending=False)

salary_rank.py
employees["salary_rank"] = employees["salary"].rank(
    method="dense",
    ascending=False
)

print(employees.sort_values("salary_rank"))
Output name department salary experience salary_rank 1 Priya HR 60000 4 1.0 2 Amit IT 55000 3 2.0 3 Sneha Finance 50000 5 3.0 0 Rahul IT 45000 2 4.0 4 Vikas HR 40000 1 5.0

salary_rank (teal) is new. With ascending=False, the highest salary gets rank 1. Ranks come back as decimals (1.0, 2.0 …) because rank() returns floats.

Implementation steps
  1. Call rank() on the salary column.
  2. Choose ascending=False so the biggest salary becomes rank 1.
  3. Store the result in a new column, salary_rank.
  4. Sort by that column to show the leaderboard.
Ties — added illustration

rank() assigns rankings based on values, and different ranking methods handle ties differently. The example below is an added illustration (not from your dataset, which has no ties): B and C both earn 55000.

rank_ties.py
import pandas as pd

salary = pd.Series([60000, 55000, 55000, 40000], index=["A", "B", "C", "D"])

for method in ["average", "min", "max", "first", "dense"]:
    print(method, salary.rank(method=method, ascending=False).tolist())

9.7

Sort Using the Index

Restore the original row order

🔢 sort_index()

sort_index.py
print(employees.sort_index())
Output name department salary experience salary_rank 0 Rahul IT 45000 2 4.0 1 Priya HR 60000 4 1.0 2 Amit IT 55000 3 2.0 3 Sneha Finance 50000 5 3.0 4 Vikas HR 40000 1 5.0
namedepartmentsalaryexperiencesalary_rank

1PriyaHR6000041.0
2AmitIT5500032.0
3SnehaFinance5000053.0
4VikasHR4000015.0

sort_index() orders rows by their index labels (0, 1, 2 …), putting them back in the original sequence — now with the salary_rank column attached.

🏭
Industry tip: sorting changes the order of the returned DataFrame. If you need to preserve the original ordering for later calculations, assign the sorted result to a new variable (for example sorted_employees), exactly as the examples in this hour do.
