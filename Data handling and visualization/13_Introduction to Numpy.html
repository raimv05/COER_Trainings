What is NumPy?

Numerical Python — built for arrays, matrices, and fast math

📘 Definition

NumPy stands for Numerical Python. It's a Python library used for numerical computing — particularly when working with arrays, matrices, mathematical calculations, and large amounts of numeric data.

1.2

Python List vs NumPy Array

Two ways to store the same five numbers — and why they behave differently

🆚 The Core Difference

A Python list is a general-purpose container — it can hold anything, of any type, mixed together. A NumPy array is purpose-built for efficient numerical operations, and it usually stores elements of a single, common data type.

list_vs_array.py
# Python list
orders_list = [120, 150, 180, 140, 210]

# NumPy array
import numpy as np
orders_array = np.array(orders_list)

print("Python list:", orders_list)
print("NumPy array:", orders_array)
OutputPython list: [120, 150, 180, 140, 210] NumPy array: [120 150 180 140 210]
General-purpose container
any type, mixed together
vs
Numerical, typed array
optimized for fast math on numbers

A list is flexible by design. A NumPy array trades some of that flexibility for speed and built-in mathematical operations — which is exactly what large numeric datasets need.

Creating NumPy Arrays

One-dimensional and two-dimensional arrays, and the properties that describe them

🧱 Building 1D and 2D Arrays

creating_arrays.py
import numpy as np

# One-dimensional array
sales = np.array([1000, 1500, 2000, 2500])

# Two-dimensional array
weekly_sales = np.array([
    [1000, 1500, 2000],
    [1200, 1800, 2200]
])

print("Sales:", sales)
print("Weekly sales:\n", weekly_sales)
print("Dimensions:", weekly_sales.ndim)
print("Shape:", weekly_sales.shape)
print("Total elements:", weekly_sales.size)
print("Data type:", weekly_sales.dtype)
OutputSales: [1000 1500 2000 2500] Weekly sales: [[1000 1500 2000] [1200 1800 2200]] Dimensions: 2 Shape: (2, 3) Total elements: 6 Data type: int64

1.5

Practical: Daily Order Analysis

Bringing 1.1–1.4 together into one runnable script

💻 scripts/hour01_numpy.py

scripts/hour01_numpy.py
import numpy as np

# Step 1: Record daily orders
orders = np.array([120, 150, 180, 140, 210])

# Step 2: Calculate statistics
total_orders = np.sum(orders)
average_orders = np.mean(orders)
highest_orders = np.max(orders)
lowest_orders = np.min(orders)

# Step 3: Display results
print("Daily orders:", orders)
print("Total orders:", total_orders)
print("Average orders:", average_orders)
print("Highest orders:", highest_orders)
print("Lowest orders:", lowest_orders)
OutputDaily orders: [120 150 180 140 210] Total orders: 800 Average orders: 160.0 Highest orders: 210 Lowest orders: 120
