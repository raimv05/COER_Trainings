3.1

What is Pandas?

A Python library for tabular, labeled data — think "Excel, but programmable"

📘 Definition

Pandas is a Python library for working with tabular and labeled data. It is used extensively in data analysis, reporting, data cleaning, and preprocessing — across almost every industry that works with structured data.

Pandas offers methods for importing data, inspecting its structure, selecting rows and columns, grouping records, and combining datasets.

3.2

Create Your First DataFrame

Building a table directly from a Python dictionary

🧱 From a Dictionary to a Table

first_dataframe.py
import pandas as pd

data = {
    "product": ["Laptop", "Mouse", "Keyboard", "Monitor"],
    "price": [50000, 500, 1500, 12000],
    "quantity": [2, 10, 4, 3]
}

df = pd.DataFrame(data)

print(df)
Output product price quantity 0 Laptop 50000 2 1 Mouse 500 10 2 Keyboard 1500 4 3 Monitor 12000 3
Python dictionary
keys → columns, lists → values
↓ pd.DataFrame(data)
Labeled DataFrame
rows numbered 0, 1, 2, 3 by default
💡
Notice the pattern: each dictionary key ("product", "price", "quantity") becomes a column name, and each corresponding list becomes that column's values, matched up by position.
3.3

Inspect a Dataset

The first thing to do with any new DataFrame — before analyzing, understand its shape

🔍 Seven Essential Inspection Commands

inspect_dataset.py
import pandas as pd

df = pd.DataFrame({
    "employee": ["Rahul", "Priya", "Amit", "Sneha"],
    "department": ["IT", "HR", "IT", "Finance"],
    "salary": [45000, 40000, 55000, 50000]
})

print(df.head())
print(df.tail(2))
print(df.shape)
print(df.columns)
print(df.dtypes)
print(df.info())
print(df.describe())
Output (abridged) employee department salary 0 Rahul IT 45000 1 Priya HR 40000 ... (4, 3) Index(['employee', 'department', 'salary'], dtype='object') employee object department object salary int64 dtype: object ... salary count 4.000000 mean 47500.000000 std 6454.972244

df.head()

Previews the first rows — 5 by default, or pass a number for a custom count.

df.tail(2)

Previews the last rows — here, the final 2.

df.shape

Reports (rows, columns) as a tuple — a quick size check.

df.columns

Lists all column names in the DataFrame.

df.dtypes

Shows the data type stored in each column — text, integer, float, etc.

df.info()

Gives structural information: row/column counts, non-null counts per column, and memory usage.

df.describe()

Returns descriptive statistics — count, mean, std, min, max, and quartiles — for suitable (numeric) columns.

📝
Make this your habit, not an afterthought: running these seven commands on any new dataset — before you write a single line of analysis — tells you its size, its column types, and whether anything looks obviously wrong, all in under a minute.

🏭
Industry tip: keep raw source files unchanged. Perform every transformation on a loaded DataFrame in memory, and save any derived output to a separate location — such as data/output/ — never back on top of the original raw file. This way, if a transformation goes wrong, your source data is always there to start over from.
