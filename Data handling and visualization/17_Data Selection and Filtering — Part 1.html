5.1

Why is Data Selection Important?

Show only what is needed, not the entire dataset

🏢 Real-World Scenario

A company has 10,000 employee records, but the HR team only wants the names and salaries of IT employees. Displaying the entire dataset would be slow, noisy and hard to read. Instead, we select only the required information.

Selection pipeline
Full Dataset10,000 rows × all columns
➜
Select Columnsname, salary
➜
Select Rowsdepartment = IT
➜
Resultonly what HR needs

Today's session covers column selection and row selection by label and position. Condition-based filtering (such as department == "IT") continues in Part 2.

🧪 Create the Dataset

We will use this small employee DataFrame for every example in this session.

import pandas as pd

employees = pd.DataFrame({

print(employees)

5.2

Select One or Multiple Columns

Using square brackets on the column label(s)

📘 Two Forms, Two Return Types

One column → df["name"]
Single brackets, one label. Returns a Series.

Multiple columns → df[["name", "salary"]]
A list inside the brackets. Returns a DataFrame.

select_columns.py
# One column: returns a Series
print(employees["name"])

# Multiple columns: returns a DataFrame
print(employees[["name", "salary"]])
Output0 Rahul 1 Priya 2 Amit 3 Sneha 4 Vikas Name: name, dtype: str name salary 0 Rahul 45000 1 Priya 40000 2 Amit 60000 3 Sneha 50000 4 Vikas 52000
📝
About dtype: str: in pandas 3.x, text columns display as str. On older versions the same line shows dtype: object. The data is identical.

⚙️ Implementation Steps
  1. Decide how many columns you needOne column gives a Series; two or more give a DataFrame.
  2. Single column: write the label in quotes inside [ ]The label must match the column name exactly, including capital letters.employees["name"]
  3. Multiple columns: put the labels in a Python listNote the double brackets. The outer pair is the selector; the inner pair is the list.employees[["name", "salary"]]
  4. Print and check the typeUse type() to confirm what came back.print(type(employees["name"])) # Series
💡
Want a one-column DataFrame? Use a list with a single label: employees[["name"]]. Single brackets give a Series; double brackets always give a DataFrame.
5.3

Using loc

Select data by row and column labels

🏷️ Label-Based Selection

Syntax: df.loc[row_labels, column_labels]. With one argument, loc selects entire rows.

loc_examples.py
print(employees.loc[0])

print(employees.loc[0:2, ["name", "salary"]])
Outputemployee_id 101 name Rahul department IT salary 45000 experience 2 Name: 0, dtype: object name salary 0 Rahul 45000 1 Priya 40000 2 Amit 60000
⚠️
Key rule: in the second statement, rows with labels 0, 1 and 2 are selected. With loc, the end label of a slice is included.
Visual: employees.loc[0:2, ["name", "salary"]]

⚙️ Implementation Steps
  1. Identify the labels you needLook at the index (rows) and the header (columns). Here the row labels are 0–4.
  2. Select one complete rowPass a single row label. The result is a Series whose index is the column names.employees.loc[0]
  3. Select a range of rowsUse start:end. Remember the end is inclusive.employees.loc[0:2]
  4. Add a list of column labels after a commaRows first, then columns, separated by a comma.employees.loc[0:2, ["name", "salary"]]
  5. Print and verifyCheck that exactly 3 rows and 2 columns came back.
5.4

Using iloc

Select data by integer position

🔢 Position-Based Selection

Syntax: df.iloc[row_positions, column_positions]. Positions always start at 0 and ignore whatever the labels are.

iloc_examples.py
print(employees.iloc[0])

print(employees.iloc[0:3, 1:4])
Outputemployee_id 101 name Rahul department IT salary 45000 experience 2 Name: 0, dtype: object name department salary 0 Rahul IT 45000 1 Priya HR 40000 2 Amit IT 60000
⚠️
Key rule: the end position of an iloc slice is excluded. So 0:3 gives positions 0, 1, 2, and 1:4 gives columns 1, 2, 3.
Visual: employees.iloc[0:3, 1:4]

⚙️ Implementation Steps
  1. Count positions from zeroRows: 0–4. Columns: employee_id=0, name=1, department=2, salary=3, experience=4.
  2. Select one row by positionReturns the first row as a Series.employees.iloc[0]
  3. Choose the row range (end excluded)To get the first three rows, write 0:3.
  4. Choose the column range (end excluded)To get name, department, salary (positions 1, 2, 3), write 1:4.
  5. Combine rows and columnsRow selector, comma, column selector.employees.iloc[0:3, 1:4]
📚
Best practice: the pandas documentation recommends explicit indexing methods such as loc and iloc for clear and predictable data access. Prefer them over ambiguous shortcuts as your scripts grow.
5.5

Select a Single Value

at for labels, iat for positions

🎯 One Cell, Fast

When you need exactly one value, at and iat return the bare value, not a Series or DataFrame.

at_iat.py
# Label-based access
print(employees.at[0, "name"])

# Position-based access
print(employees.iat[0, 1])
OutputRahul Rahul
Two routes to the same cell
⚙️ Implementation Steps
  1. Pick the exact cellRow 0 (Rahul's record) and the name column.
  2. Use at when you know labelsRow label first, column label second.employees.at[0, "name"]
  3. Use iat when you know positionsRow position first, column position second (name is column 1).employees.iat[0, 1]
  4. Confirm both give the same answerBoth print Rahul.

Common Mistakes

Errors students make most often in this topic

1️⃣
Forgetting the list for several columns
df["name", "salary"] raises a KeyError. Use df[["name", "salary"]].
2️⃣
Mixing up the slice end
loc[0:2] gives 3 rows; iloc[0:2] gives only 2 rows (positions 0 and 1).
3️⃣
Using a position inside loc
Column names go in loc; loc[0, 1] fails because 1 is not a column label.
4️⃣
Wrong capitalisation
Labels are case-sensitive: df["Name"] is not df["name"].
