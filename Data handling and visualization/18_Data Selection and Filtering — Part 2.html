What is Filtering?

Select only the records that satisfy a condition

🛒 Real-World Scenario

An e-commerce manager wants to find four different groups of products. Each request is one kind of filter:

6.2

Filter Using One Condition

A comparison creates a True/False mask; the mask selects the rows

1️⃣ Products Priced Above ₹1,000

filter_one_condition.py
expensive_products = products[products["price"] > 1000]

print(expensive_products)
Output product category price stock 0 Laptop Electronics 50000 10 2 Keyboard Accessories 1500 8 3 Monitor Electronics 12000 5 4 Webcam Accessories 2500 15
What happens inside: the boolean mask

Pandas first evaluates products["price"] > 1000 row by row, producing True/False. Then products[mask] keeps the True rows. The Mouse (₹500) is the only row dropped.

The same thing in two explicit steps (useful for debugging and teaching):

mask_two_steps.py
mask = products["price"] > 1000
print(mask)

print(products[mask])
Output0 True 1 False 2 True 3 True 4 True Name: price, dtype: bool product category price stock 0 Laptop Electronics 50000 10 2 Keyboard Accessories 1500 8 3 Monitor Electronics 12000 5 4 Webcam Accessories 2500 15
📝
Notice the index: the filtered result keeps the original row labels (0, 2, 3, 4). Row 1 is missing, not renumbered. This is why labels matter, as you saw with loc in Part 1.
⚙️ Implementation Steps
  1. Pick the column to testWe test the price column.products["price"]
  2. Write the comparisonUse >, <, >=, <=, == or !=. This creates the boolean mask.products["price"] > 1000
  3. Put the mask inside square brackets of the DataFrameThe DataFrame keeps the rows where the mask is True.products[products["price"] > 1000]
  4. Store the result in a new variableThe original products is not changed.expensive_products = ...
  5. Print and verifyCheck that only the Mouse (₹500) is missing.
6.3

Filter Using Multiple Conditions

& means AND, | means OR, and every comparison needs its own parentheses

🔗 AND: both conditions must be true

Products costing more than ₹1,000 AND with stock below 10:

filter_and.py
# Products costing more than ₹1,000 AND stock below 10
result = products[
    (products["price"] > 1000) &
    (products["stock"] < 10)
]

print(result)
Output product category price stock 2 Keyboard Accessories 1500 8 3 Monitor Electronics 12000 5

With AND, a row is kept only when every mask column is True (green & green).

Venn view: AND keeps the overlap
⚙️ Implementation Steps (AND)
  1. Write each condition separatelyOne test per column.products["price"] > 1000 products["stock"] < 10
  2. Wrap each condition in parenthesesThis is required because & binds tighter than > and <.(products["price"] > 1000) (products["stock"] < 10)
  3. Join them with &Use &, not the Python word and.
  4. Place the whole expression inside products[ ... ]Putting each part on its own line keeps it readable.
  5. Print and verifyExpected rows: Keyboard and Monitor.

🔀 OR: at least one condition must be true

Products costing less than ₹1,000 OR with stock below 10:

filter_or.py
# Products costing less than ₹1,000 OR stock below 10
result = products[
    (products["price"] < 1000) |
    (products["stock"] < 10)
]

print(result)
Output product category price stock 1 Mouse Accessories 500 50 2 Keyboard Accessories 1500 8 3 Monitor Electronics 12000 5

With OR, a row is kept when at least one mask column is True. Mouse passes on price; Keyboard and Monitor pass on stock.

Venn view: OR keeps everything inside either circle
&
AND is strict: fewer rows. Each added condition can only remove rows.
|
OR is generous: more rows. Each added condition can only add rows.
⚙️ Implementation Steps (OR)
  1. Write the two conditions in parenthesesSame rule as AND.(products["price"] < 1000) (products["stock"] < 10)
  2. Join them with the pipe symbol |Use |, not the Python word or.
  3. Filter the DataFramePlace the expression inside products[ ... ].
  4. Print and verifyExpected rows: Mouse, Keyboard, Monitor.
⚠️
Parentheses are not optional. Without them, Python reads 1000 & products["stock"] first and Pandas raises ValueError: The truth value of a Series is ambiguous. See Common Mistakes below.
6.4

Filter by Category

Use == to match an exact text value

🏷️ Accessories Only

filter_category.py
accessories = products[
    products["category"] == "Accessories"
]

print(accessories)
Output product category price stock 1 Mouse Accessories 500 50 2 Keyboard Accessories 1500 8 4 Webcam Accessories 2500 15
⚠️
== is a comparison; = is an assignment. Write == "Accessories" to test equality. Text matching is also case-sensitive: "accessories" would match nothing.
⚙️ Implementation Steps
  1. Select the text columnThe column that holds the categories.products["category"]
  2. Compare with == to the exact textSpelling and capital letters must match the data exactly.products["category"] == "Accessories"
  3. Use the mask to filterWrap it in products[ ... ].
  4. Print and verifyExpected rows: Mouse, Keyboard, Webcam.
6.5

Use isin()

Test whether a value belongs to a list of allowed values

📋 Match Any Value in a List

filter_isin.py
selected_categories = products[
    products["category"].isin(["Electronics", "Accessories"])
]

print(selected_categories)
Output product category price stock 0 Laptop Electronics 50000 10 1 Mouse Accessories 500 50 2 Keyboard Accessories 1500 8 3 Monitor Electronics 12000 5 4 Webcam Accessories 2500 15

This example selects both categories, so every row is kept. In practice, isin() is particularly useful when filtering for a smaller set of values from a much larger category list.

A more selective list: .isin(["Electronics"])
💡
Why not just use OR? isin(["A", "B", "C", "D"]) is much shorter than four == tests joined by |, and it scales to long lists without extra parentheses.
⚙️ Implementation Steps
  1. Decide the allowed valuesWrite them as a Python list.["Electronics", "Accessories"]
  2. Call .isin() on the columnIt returns True where the value is in the list.products["category"].isin([...])
  3. Filter with the maskWrap in products[ ... ].
  4. Try a shorter listChange the list to ["Electronics"] and confirm only Laptop and Monitor remain.
6.6

Filter Text

Find rows whose text contains a pattern, using str.contains()

🔎 Product Names Containing "cam"

filter_text.py
matches = products[
    products["product"].str.contains("cam", case=False, na=False)
]

print(matches)
Output product category price stock 4 Webcam Accessories 2500 15

The expression finds product names containing "cam", ignoring letter case. "Webcam" matches because it contains cam.

Anatomy of the expression
📝
Why na=False? If a name is missing, contains() would return NaN instead of True/False, and the filter would fail. na=False says "a missing name does not match."
Also remember: by default contains() treats the pattern as a regular expression. Plain letters like "cam" work as expected.
⚙️ Implementation Steps
  1. Select the text columnIt must contain text values.products["product"]
  2. Open the string tools with .strAll text methods live under this accessor.
  3. Call contains() with the patternAdd case=False to ignore capital letters, and na=False to handle missing text..str.contains("cam", case=False, na=False)
  4. Filter with the maskWrap in products[ ... ].
  5. Print and verifyExpected row: Webcam.
6.7

Handle Missing Values in Filters

Keep only rows where a value actually exists, using notna()

🕳️ Products That Have a Stock Value

filter_missing.py
products_with_stock = products[
    products["stock"].notna()
]

print(products_with_stock)
Output product category price stock 0 Laptop Electronics 50000 10 1 Mouse Accessories 500 50 2 Keyboard Accessories 1500 8 3 Monitor Electronics 12000 5 4 Webcam Accessories 2500 15

Our dataset has no missing values, so every row is kept. The filter only shows its value when data is missing. Try it below.

Demo: the same filter when two stock values are missing

In real files, empty cells are loaded as NaN (shown in red). notna() is True where a value exists, so the Mouse and Webcam rows are dropped.

filter_missing_demo.py
import numpy as np

demo = products.copy()
demo["stock"] = [10, np.nan, 8, 5, np.nan]

print(demo[demo["stock"].notna()])
Output product category price stock 0 Laptop Electronics 50000 10.0 2 Keyboard Accessories 1500 8.0 3 Monitor Electronics 12000 5.0
💡
Why do the stock numbers now show 10.0? Missing values are stored as floating-point NaN, so a column containing one becomes decimal. The opposite filter, isna(), selects the rows that are missing.
⚙️ Implementation Steps
  1. Choose the column to checkHere, stock.
  2. Call .notna()Returns True for real values and False for missing ones.products["stock"].notna()
  3. Filter with the maskOnly rows with a stock value remain.
  4. Print and verifyCompare the row count before and after to see how many rows had missing stock.

Common Mistakes

Errors students make most often in this topic

1️⃣
Missing parentheses
products["price"] > 1000 & products["stock"] < 10
raises ValueError: The truth value of a Series is ambiguous. Wrap each condition: (…) & (…).
2️⃣
Using and / or
Python's words work on single True/False values, not whole columns. Use & and |.
3️⃣
= instead of ==
products["category"] = "Accessories" would overwrite the column. Comparison needs two equals signs.
4️⃣
Case-sensitive text
== "accessories" matches nothing. Match the exact case, or use str.contains(..., case=False).
5️⃣
Passing a string to isin()
isin("Electronics") fails. It needs a list: isin(["Electronics"]).
6️⃣
Forgetting na=False
Text filters on columns with missing names return NaN and break the filter. Add na=False.
