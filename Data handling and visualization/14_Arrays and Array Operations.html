2.1

Arithmetic Operations

Doing math across an entire array at once — no explicit loop required

🛒 Setting Up: A Small Store's Inventory

Suppose a store sells three products. Their prices and quantities are:

ProductPrice (₹)Quantity
Laptop50,0002
Mouse50010
Keyboard1,5004

NumPy lets us perform arithmetic on entire arrays without writing an explicit loop for every element.

store_revenue.py
import numpy as np

prices = np.array([50000, 500, 1500])
quantities = np.array([2, 10, 4])

revenue = prices * quantities

print("Revenue per product:", revenue)
print("Total revenue:", np.sum(revenue))
OutputRevenue per product: [100000 5000 6000] Total revenue: 111000
prices = [50000, 500, 1500]
× (element-wise)
quantities = [2, 10, 4]
↓
revenue = [100000, 5000, 6000]

Each position multiplies against its matching position — index 0 with index 0, index 1 with index 1, and so on — all in one line.

➗ The Five Core Operations

element_wise_ops.py
a = np.array([10, 20, 30])
b = np.array([2, 4, 5])

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a ** 2)
Output[12 24 35] [ 8 16 25] [ 20 80 150] [5. 5. 6. ] [100 400 900]
+addition
−subtraction
×multiplication
÷division
**power
💡
The key word is "element-wise": these operations run position-by-position across the arrays when their shapes are compatible — same length here. There's no hidden loop to write; NumPy handles the iteration internally and far faster than a Python for loop would.
2.2

Indexing and Slicing

Pulling out exactly the elements you need, by position or by range

🔎 Five Ways to Access Array Data

indexing_slicing.py
import numpy as np

sales = np.array([1000, 2000, 3000, 4000, 5000])

print(sales[0])      # First element
print(sales[-1])     # Last element
print(sales[1:4])    # Index 1 through 3
print(sales[:3])     # First three elements
print(sales[::2])    # Every second element
Output1000 5000 [2000 3000 4000] [1000 2000 3000] [1000 3000 5000]

sales[0] — the first element:

1000[0]
2000[1]
3000[2]
4000[3]
5000[4] / [-1]

sales[1:4] — index 1 up to, but not including, index 4:

1000[0]
2000[1]
3000[2]
4000[3]
5000[4]

sales[::2] — every second element, starting from index 0:

1000[0]
2000[1]
3000[2]
4000[3]
5000[4]
📝
Two rules to never forget: Python indexing always starts at 0, not 1. And in a slice like [1:4], the ending position is excluded — you get indexes 1, 2, and 3, never 4.

Two-Dimensional Arrays

Rows and columns — and three different ways to slice into them

🏬 Sales Across Three Stores

store_matrix.py
import numpy as np

# Rows represent stores; columns represent Monday, Tuesday, Wednesday
sales = np.array([
    [1000, 1200, 1500],
    [2000, 1800, 2200],
    [1500, 1700, 1600]
])

print("All sales:\n", sales)
print("First store:", sales[0])
print("Monday sales:", sales[:, 0])

Aggregation by Axis

Summing down columns vs summing across rows — and how to tell NumPy which one you mean

📊 Totals Three Different Ways

axis_aggregation.py
import numpy as np

sales = np.array([
    [1000, 1200, 1500],
    [2000, 1800, 2200],
    [1500, 1700, 1600]
])

print("Total sales:", sales.sum())
print("Total for each day:", sales.sum(axis=0))
print("Total for each store:", sales.sum(axis=1))

2.5

Broadcasting

Operating an array against a single scalar value, with no manual duplication

📈 Example: A 10% Price Increase

Broadcasting allows compatible arrays and scalar values to participate in the same operation without you manually copying that scalar to match the array's length.

broadcasting.py
import numpy as np

prices = np.array([100, 200, 300])
updated_prices = prices * 1.10

print("Original prices:", prices)
print("Updated prices:", updated_prices)
OutputOriginal prices: [100 200 300] Updated prices: [110. 220. 330.]
100
200
300
×
1.10
=
110
220
330

NumPy automatically "stretches" the single scalar 1.10 across every element of prices — you write one multiplication, and it applies everywhere.

💡
Without broadcasting, you'd have had to build a same-length array of 1.10 values yourself just to multiply element-by-element. Broadcasting removes that step entirely whenever the shapes are compatible.

Reshaping Arrays

Changing the shape of your data without changing its values

🧩 From a Flat List to a Grid

reshaping.py
import numpy as np

values = np.arange(1, 13)
matrix = values.reshape(3, 4)

print("Original array:", values)
print("Reshaped array:\n", matrix)

The non-negotiable rule: the total number of elements must stay compatible with the requested shape. 12 elements can become (3, 4), (4, 3), (2, 6), or (12, 1) — but never (3, 5), since 3 × 5 = 15 ≠ 12.
